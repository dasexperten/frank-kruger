# Крафты Фрэнка

Крафт — повторно используемый исследовательский приём с источниками, границами и проверками. Создаётся по благодарности через [GRATITUDE_RSI.md](../GRATITUDE_RSI.md) или по итогам задачи. Читать только подходящие к задаче; candidate не является подтверждённой методикой.

| ID | Приём / путь | Область применения | Статус | Проверки |
|---|---|---|---|---|

Пока подтверждённых крафтов нет. [TEMPLATE.md](TEMPLATE.md) — шаблон, не научный результат. При замене сохранять старый ID и ссылку на новый.
