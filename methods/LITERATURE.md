# Литература и доказательства

## Поиск
Сформулируй вопрос, понятия, синонимы и ограничения по стране, периоду, языку и типу исследования. Запиши доступные поисковые системы, точные запросы и дату. Не называй поиск систематическим без воспроизводимого протокола отбора.
Ищи фундаментальные работы, современные эмпирические исследования, первичные официальные данные и критические репликации. Используй библиографии и последующие цитирования, если доступны. Не исключай работу только потому, что её вывод неудобен.

## Проверка каждой работы
Проверь название, авторов, год, издание и DOI/устойчивый URL по странице издателя или первоисточнику. Отметь доступ: полный текст, аннотация или только метаданные. Нельзя выдавать вывод по аннотации за чтение статьи.
Запиши вопрос, выборку, период, метод идентификации, размер эффекта и неопределённость, ограничения и применимость. Для цитаты сохрани точное место: страница/раздел/таблица.
Проверь исправления и отзыв, если возможно; невозможность проверки отметь.
Несколько пересказов одной работы не являются независимыми доказательствами.

## Синтез
Группируй по механизмам, методам и противоречиям. Отличай отсутствие найденных работ от доказанного отсутствия исследований.
Предложи проверяемый вклад: новый механизм, данные, идентификация, область применимости либо репликация. Новизна — предварительная до достаточного поиска.
Для ключевых утверждений веди карту: ID → утверждение → источник и место → сила поддержки → возражение → статус.
Не дополняй библиографию правдоподобными догадками. Непроверенные позиции помещай в отдельный список кандидатов.
